# Exploratory Factor Analysis of Salespeople Factors

## About
This project applies Exploratory Factor Analysis (EFA) to examine the underlying structure of salespeople-related variables. The analysis explores variable correlations, estimates a two-factor solution, and evaluates model fit using R.

## Project Analysis
- [**View Full Analysis on RPubs**](https://rpubs.com/sandraberlianaputri/factor-analysis-salespeople)

## Dataset

The dataset contains salespeople-related variables analyzed to identify underlying factors through Exploratory Factor Analysis (EFA).

- **Variables:** Multiple quantitative variables related to salespeople
- **Preprocessing:** The first column was removed, and the remaining variables were standardized because they were measured on different scales.
- **Variable selection:** Variables X5 and X6 were excluded during model refinement based on their communalities.

## Methods
- **Data Standardization:** Standardizing variables measured on different scales.
- **Correlation Analysis:** Examining relationships among variables.
- **Factor Extraction:** Applying the Minimum Residual (MINRES) method and using a scree plot to explore factor retention.
- **Factor Rotation:** Applying Varimax rotation to improve factor interpretability.
- **Factor Scores:** Estimating scores for the extracted factors.
- **Model Fit Assessment:** Calculating the overall Root Mean Square (RMS) measure.
